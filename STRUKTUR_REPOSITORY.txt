PENGGUNAAN REPOSITORY INI:
==========================

1. CLONE
   git clone https://github.com/username/ritelai-jabodetabek.git
   cd ritelai-jabodetabek

2. VERIFIKASI INTEGRITAS
   cd data/
   sha256sum -c checksums.sha256
   # Semua file harus menunjukkan "OK"

3. LOAD DATA DI PYTHON
   import pandas as pd
   import geopandas as gpd

   # Load grid dengan predictors
   alfamart = pd.read_parquet("data/grid/grid_alfamart_x1_x35.parquet")

   # Load geometries
   geom = gpd.read_file("data/grid/grid_geometry_100m.gpkg", layer="grid_100m")

   # Join
   grid = geom.merge(alfamart, on="GRID_ID", how="inner")

4. BACA DOKUMENTASI
   - README.md: Overview & quick start
   - DATA_DICTIONARY.md: Detail X1-X35
   - REPRODUCE.md: Cara menggunakan data & interpretasi
